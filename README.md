\# XER Quality Checker



A professional schedule quality analysis tool for Primavera P6 `.xer` files.  

This application evaluates schedule logic, float values, relationship types, and activity durations, providing detailed reports through a clean and intuitive GUI.



\---



\## 🚀 Overview



XER Quality Checker is designed for planners, schedulers, and project controls professionals who need fast and reliable schedule quality diagnostics.  

The tool performs multiple industry-standard checks and presents results in a user-friendly interface with export options.



\---



\## ✨ Features



\### ✔ Schedule Quality Checks

\- FF + SS relationship ratio (must be ≤ 20%)

\- SF relationships (should not exist)

\- Lag usage detection

\- Open-Start activities

\- Open-Finish activities

\- Long-duration activities (> 14 days)

\- High float activities (> 20% of project duration)



\### ✔ Reporting \& Visualization

\- Full GUI (Tkinter)

\- Detailed activity lists

\- Description panel for long explanations

\- PDF export

\- Excel export



\### ✔ Compatibility

\- Works with Primavera P6 `.xer` files

\- Windows EXE version available (no Python required)

\- Python source code included for developers
